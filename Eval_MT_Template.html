Workflow:
1. Eval: all 9 competencies are mandatory. Pick a grade (1-5) per card - guidance hint appears (G4 = tight, G3/G5 = evidence, G2 = watertight). Even a one-liner is fine where nothing significant happened.
2. MT: use toggle buttons to open the competencies relevant to MT (typically 2-4). Set the MT Objectives status (OA / OAWAP / ONA).
3. Root-cause: if MT status = OAWAP or ONA, tick the root-cause box on the 1-2 competencies that drove it. Max 2; ideally 1. The artifact will warn if more than 2.
4. Click Send to Claude for review, paste into chat for House Style Check.
5. Copy each field into TMS. Eval = first page, MT = second page. Submit, then click Save Final Record.
6. Open a separate copy of this file for the other pilot - completely isolated state, no edit bleed.
